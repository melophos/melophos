# Studio source

| File | Purpose |
| --- | --- |
| `main.ts` | Entry point: builds the keyboard and connects MIDI on request |
| `midi.ts` | WebMIDI access and note message parsing |
| `keyboard.ts` | On-screen keyboard that highlights pressed keys |
| `notes.ts` | Note names, black-key detection and key ranges |
| `profile.ts` | The default instrument profile |
| `style.css` | Styles, with a high-contrast pressed colour and reduced-motion support |
| `notes.test.ts` | Unit tests for note handling and MIDI parsing |
