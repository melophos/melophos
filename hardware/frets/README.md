# Fret bar

A flexible LED grid under or beside the strings: one LED per string per fret, wired as a serpentine so rows alternate direction.

Planned for v3 with the guitar profiles. The layout it drives is described in [profiles/guitar-6-standard.json](https://github.com/melophos/profiles/blob/main/guitar-6-standard.json).

## Open questions
