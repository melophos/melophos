Welcome to MELOPHOS
MELOPHOS is an open instrument learning platform. A small hub lights the notes to play on a keyboard or a guitar, records every note played and turns practice into data you can see.

This server is where we talk. GitHub is where the project is written down: the code, the issues, the releases and the long discussions. Nothing you need is only here.

The project: <https://github.com/melophos/melophos>
