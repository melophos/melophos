Good to know
- This server is quiet by default. You are only notified when someone mentions you.
- You can change which channels you see at any time in {nav:customize}.
- Type / to see our commands. {command:help} lists them.
- To report a message to the moderators, press and hold it or right-click it, choose Apps, then Report to moderators.
- What happens to personal data here: <https://github.com/melophos/melophos/blob/main/docs/community-privacy.md>
