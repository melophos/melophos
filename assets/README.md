# Assets

Images and media for MELOPHOS, kept in one place so they never scatter across component folders.

| Folder | Contents |
| --- | --- |
| [`brand/`](brand/) | Logo, wordmarks, social preview card, colours and usage rules |
| [`photos/`](photos/) | Build photos: boards, bars, enclosures and the hub on real instruments |
| [`diagrams/`](diagrams/) | Architecture, wiring and signal-flow diagrams |
| [`renders/`](renders/) | KiCad 3D renders and enclosure renders |
| [`screenshots/`](screenshots/) | Studio and dashboard screenshots |

## Conventions

- Lowercase names with hyphens, starting with the subject: `hub-rev-a-top.jpg`, `studio-practice-view.png`.
- Photos as JPEG at no more than 2000 px on the long edge. Diagrams and logos as SVG where possible, PNG otherwise.
- Every image used in the docs has alt text where it is embedded.

> [!TIP]
> Export diagrams as SVG from their source tool and commit the source file next to the export, so anyone can edit them later.
