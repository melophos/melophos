# Brand

The MELOPHOS mark is three piano keys seen from above with the middle key lit and a point of light above it: a song made visible.

| File | Use |
| --- | --- |
| [`melophos-mark.svg`](melophos-mark.svg) | App icon and avatar, on its own dark tile |
| [`melophos-mark-512.png`](melophos-mark-512.png), [`melophos-mark-1024.png`](melophos-mark-1024.png) | Raster avatar for GitHub, social sites and favicons |
| [`melophos-mark-transparent.svg`](melophos-mark-transparent.svg) | Mark without a tile, for light backgrounds |
| [`melophos-wordmark-dark.svg`](melophos-wordmark-dark.svg) | Mark and name on dark backgrounds |
| [`melophos-wordmark-light.svg`](melophos-wordmark-light.svg) | Mark and name on light backgrounds |
| [`melophos-social-preview.png`](melophos-social-preview.png) | 1280 by 640 card shown when a repository link is shared |

The name in the wordmarks is converted to outlines, so it renders the same everywhere without the font installed.

## Colours

| Role | Hex |
| --- | --- |
| Light (accent) | `#FFB000` |
| Ink | `#0E0E12` |
| Key | `#F2F2F5` |
| Paper | `#F7F7F5` |

Amber is the accent because it stays distinct for the common forms of colour blindness and reads well on both ink and paper.

## Type

Space Grotesk Bold for the wordmark and headings, with slightly open letter spacing.

## Using the mark

- Keep clear space around the mark of at least a quarter of its width.
- Do not recolour the lit key or the light; amber is the one constant across every variant.
- Do not stretch, rotate or add effects.
