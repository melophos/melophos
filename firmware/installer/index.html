Install MELOPHOS hub firmware

This page puts the hub firmware on an ESP32-S3 or ESP32 board over USB. It works in Chrome or Edge on a computer. Safari and Firefox cannot do it and neither can a phone.

Before you start

  1. Plug the board into the computer with a USB cable that carries data.
  2. Close any other program that has the board's serial port open.
  3. Select Install and choose the board's port in the list the browser shows.

This browser cannot install firmware. Open this page in Chrome or Edge on a computer. This page must be opened over https to install firmware.

The installer erases the board's flash when you tick the erase option, which removes saved profiles. Leave it unticked to keep them. Later updates over Wi-Fi never erase profiles.

Nothing here has been tried on a hub board yet.
