# Integrations

Each integration stays off until its settings are present in the environment. Setup for each one is in [integrations.md](https://github.com/melophos/docs/blob/main/integrations.md).

| Module | What it does |
| --- | --- |
| `spotify.py` | Links a Spotify account with listening scopes only, to build a learn list |
| `wled.py` | Turns notes into WLED light states, one colour per pitch class |
| `webhook.py` | Builds the payload posted to `SESSION_WEBHOOK_URL` when a session finishes |
